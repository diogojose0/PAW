# PAW Marketplace

Backend application for a supermarket marketplace developed as an academic web development project.

## Features

- User authentication and authorization
- Product and category management
- Shopping and order management
- Delivery management
- Product reviews
- Stripe checkout integration
- Email notifications
- REST API

## Tech Stack

- Node.js
- Express.js
- MongoDB
- JWT
- Stripe
- JavaScript
